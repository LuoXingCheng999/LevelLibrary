# LevelLibrary（谱面库）— ADOFAI Mod

一个「冰与火之舞 / A Dance of Fire and Ice」的谱面库 mod。

## 功能
- 主界面传送门进入，字母排序 + 搜索
- 一键打开编辑器载入谱面，自动录入 / 自动标记 / 备份驱动
- 成就系统 + 每日成就
- 自动评级（AutoRating 复刻）、批量评级、导出手动标记数据
- 选择关卡文件弹窗

## 安装
用 Unity Mod Manager（UMM）导入仓库里的 `LevelLibrary_vX.Y.Z.zip`。

> 最新发布包见仓库根目录的 `LevelLibrary_v4.19.14.zip`
